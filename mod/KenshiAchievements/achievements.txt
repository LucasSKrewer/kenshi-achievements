# Conquistas do Kenshi Achievements — edite à vontade, é lido quando o jogo abre.
#
# Formato:  id | métrica | alvo | título | descrição
#
# Métricas:
#   kills, kos, takedowns (kills + KOs)        -> total do seu grupo
#   char_kills, char_kos                       -> o melhor personagem sozinho
#   race_kills:<Raça>, race_kos:<Raça>         -> ex.: race_kills:Shek, race_kills:*Beak Thing
#   faction_kills:<Facção>, faction_kos:<Facção> -> ex.: faction_kills:*Holy Nation*
#
# Raça/facção usam o nome do jogo em inglês (maiúsculas não importam). `*` casa qualquer
# trecho: útil com mods como o Genesis, que criam variantes ("*Skeleton*" pega Skeleton MKI,
# MKII, Screamer...). O `id` não pode mudar depois de liberado, senão a conquista volta a
# ficar travada nos saves antigos.

# Som ao liberar uma conquista:
#   @som = Notifications:Building_Complete -> som do próprio Kenshi (padrão), respeita o volume do jogo.
#       Outras notificações do jogo: Notifications:Thing_Complete, Notifications:Raid,
#       Notifications:Bounty_Fulfilled, Notifications:New_Biome
#       Outros eventos: Character_Unlock_Success, Stats_Open, Tech_Open, Building_Confirm
#   @som = achievement.wav                 -> qualquer .wav nesta pasta (o sino incluso, ou o seu)
#   @som = nenhum                          -> sem som
@som = Notifications:Building_Complete
