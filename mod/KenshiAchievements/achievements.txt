# Conquistas do Kenshi Achievements — edite à vontade, é lido quando o jogo abre.
#
# Formato:  id | métrica | alvo | título | descrição
#
# Métricas:
#   kills, kos, takedowns (kills + KOs)        -> total do seu grupo
#   char_kills, char_kos                       -> o melhor personagem sozinho
#   race_kills:<Raça>, race_kos:<Raça>         -> ex.: race_kills:Shek, race_kills:Beak Thing
#   faction_kills:<Facção>, faction_kos:<Facção> -> ex.: faction_kills:Holy Nation
#
# Raça/facção usam o nome exato do jogo (em inglês). O `id` não pode mudar depois
# de liberado, senão a conquista volta a ficar travada nos saves antigos.

# Som ao liberar uma conquista:
#   @som = achievement.wav   -> qualquer .wav nesta pasta (padrão)
#   @som = Change_Level      -> um som do próprio Kenshi, respeita o volume do jogo. Outros:
#                               Notifications, Character_Unlock_Success, Building_Confirm,
#                               Research_Tab, Stats_Open, Tech_Open, General_Click
#   @som = nenhum            -> sem som
@som = achievement.wav
